# Grace Music Player downloads

Download Grace Music Player from the [latest release](https://github.com/youngkwangk/grace-player-downloads/releases/latest).

- **Mac:** choose the Apple Silicon (`arm64`) or Intel (`x64`) DMG and drag Music Player to Applications. Mac release builds are signed and notarized.
- **Windows:** use the x64 installer (`.exe`) for in-app updates. The ZIP is a portable version and does not support in-app updates. Windows builds are currently unsigned.

The app can check this repository for updates, download a new version when requested, and restart after saving the current session. Versions before 2.4.1 must be updated manually once to switch to this public update feed.

This repository contains installers, update manifests, checksums, and release notes. Development source and Git history are maintained in a separate private repository.
